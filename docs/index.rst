Overview
--------

The Text Processing Toolkit provides a modular and extensible framework for building text processing applications. Built using the Polylith architecture, it ensures high maintainability, code reusability, and scalability.

**Key Features:**

* **Polylith Architecture** - Components-first modular design
* **Python 3.12+** - Modern Python with type safety
* **SIMD Acceleration** - High-performance string operations
* **Comprehensive Testing** - Robust test suite with pytest
* **Type Safety** - Full type annotations and mypy checking
